# Картинки и аудио курса

Кладите файлы в папку юнита: `media/u1/`, `media/u2/` и т. д.
Имена — латиницей, без пробелов: `u1-reading-photo.jpg`, `u1-listening-1.mp3`.

Рекомендации по размеру:
- картинки: JPG или WebP, по длинной стороне 1200–1600 px, до 300–500 КБ;
- аудио: MP3, 64–96 kbps моно (речь звучит хорошо), до 10 МБ на файл.

Файлы на GitHub Pages публичные: любой, у кого есть точная ссылка, может их открыть.
Скрипты аудиозаписей (transcript) сюда не кладите — пишите их в `course.json` блоком `teacher-note`.
